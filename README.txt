Hybrid Telecom Graph Dataset
============================

Input: Telecom_Network_Data.csv
Original records: 3605
Hybrid records: 4445
Synthetic records: 840
Timestamp graphs: 769
Queries: 75

Telecom_Hybrid.csv preserves all original rows unchanged, marked data_source=original.
Artificial records are labelled synthetic_same_timestamp or synthetic_new_timestamp.
DatabaseX.txt contains one graph per timestamp, one graph per line.
Each graph is a comma-separated sequence of assignment-format triples.
QLogX.txt contains one query per line; paths in a multi-path query are comma-separated.

Synthetic values are generated by perturbing existing observations. They are artificial,
not real network measurements. Derived users_band and latency_band attributes support
categorical queries because the assignment's path language does not specify numeric
comparison operators.

Before submitting, replace X in DatabaseX.txt and QLogX.txt with your actual group number.
